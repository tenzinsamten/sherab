- (direction) User wants: teacher adds more than one content item in a syllabus (e.g. two songs under Song, each with links and all)
- (direction) User wants: option to upload a PDF of any document the teacher wants as part of the syllabus
- (decision) Stance: Facilitator. Batch: Brain Writing Round Robin, then Question Storming
- (technique) started Brain Writing Round Robin
- (idea) A song item has a title
- (idea) A song item holds the lyrics
- (idea) A song item has a YouTube link
- (idea) A song item has an audio link
- (idea) A song item can carry a PDF
- (idea) A song item has a description of the song (added from the student's point of view)
- (insight) From the parent's seat the song item (title, description, lyrics, YouTube link, audio link, PDF) looks complete; nothing to add
- (insight) The same item shape (title, description, lyrics/text, YouTube link, audio link, PDF) is enough for language and dance too; no area needs its own fields
- (technique) started Question Storming
- (question) What is the maximum file size for an upload?
- (question) Which file types are allowed?
- (question) A file is uploaded, then the teacher updates the document: how do they upload the new one in its place?
- (decision) Syllabus files and items are visible only to the students, parents and teachers of that class
- (question) With many items in an area, how are they sorted?
- (question) With many items, how does someone search for one?
- (question) Can the teacher archive or delete old items (and their files) when a year ends?
- (direction) Correction to candidate 1: a class has a syllabus for a year, and under that syllabus the teacher can add more sections (e.g. one section per song); not 'several items per area'
- (decision) MoSCoW: a separate lyrics/text field per section is not required (dropped)
- (decision) MoSCoW verdict (user): Must = add sections under the class's yearly syllabus, section title, section description
- (decision) MoSCoW verdict (user): Should = replace an uploaded file, sort sections, search sections, archive or delete old sections
- (decision) MoSCoW verdict (user): Could = lyrics/text field (4), YouTube link, audio link, PDF upload
- Two tensions in the verdict, raised with the user: 4 was dropped a turn earlier but is now Could; replace-file (8) is Should while PDF upload (7), which it depends on, is Could
- (decision) Final MoSCoW (user): Must = add sections under the class's yearly syllabus, section title, section description, PDF upload. Should = replace an uploaded file, sort, search, archive or delete sections. Could = YouTube link, audio link. Won't = separate lyrics/text field
- (insight) User's conclusion: sections with PDF upload is the main thing
- (insight) Coach: today a class has one syllabus per school year holding one rich-text content, a language and up to 10 links (class_syllabi, 0015/0035). A section is that same body repeated, so the rich-text description already covers lyrics (dropped field 4) and the existing link rows already cover YouTube and audio links (Could 5, 6)
- (insight) Coach: PDF upload is the only truly new capability; the app stores no files today. The class-only visibility decision means files must be private, not public links, and that is the hardest part of the Must
- (insight) Coach: 'replace a file' and 'archive or delete old sections' are one question, the life of a file: what happens to the stored PDF when it is replaced, archived, deleted, or the year ends
- (insight) Coach: open for planning: what becomes of each class's existing syllabus content and links when sections arrive (e.g. it becomes the first section)
- (insight) Still unanswered from Question Storming: maximum file size, allowed file types (PDF only?), default sort order of sections, how search works
